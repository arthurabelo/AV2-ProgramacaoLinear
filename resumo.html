Simplex — o algoritmo

Critério de entrada

Na linha z, escolhe-se a variável com o coeficiente mais negativo.
(equivale ao maior ganho por unidade)

Critério de saída

Menor razão bᵢ / aᵢₖ entre as linhas com aᵢₖ > 0.
Empate → escolha arbitrária (degeneração).

Pivotear

1. Divida a linha do pivô pelo pivô.
2. Para as demais linhas: Lᵢ ← Lᵢ − aᵢₖ·L_pivô.

Parar quando

Todos os coeficientes de z forem ≥ 0 → ótimo.
Coeficiente 0 em variável não-básica → múltiplos ótimos.

Lê a solução:   básicas = coluna b  ·  não-básicas = 0  ·  z = valor na linha z

M Grande & duas fases

M Grande:   max z − M·Σaᵢ    (M ≫ qualquer coeficiente)
Duas fases:   Fase 1 → min Σaᵢ  |  se min = 0, viável  ;  Fase 2 → otimizar o z real

Regra: ≤ → folga · ≥ → excesso + artificial · = → artificial.

Convexidade

S convexo ⇔ (1−α)x + αy ∈ S  ∀x,y ∈ S, α ∈ [0,1]
conv(S) = menor conjunto convexo que contém S

Compacto = fechado + limitado. Weierstrass: f contínua em compacto atinge mínimo e máximo.

Separação: S convexo fechado, y ∉ S ⇒ ∃p ≠ 0, α com pᵗy > α e pᵗx ≤ α ∀x ∈ S.

Sistemas lineares

Substituição retroativa:   xᵢ = (bᵢ − Σj>i aᵢⱼxⱼ) / aᵢᵢ
Jacobi:   xᵢ⁽ᵏ⁺¹⁾ = (bᵢ − Σj≠i aᵢⱼxⱼ⁽ᵏ⁾) / aᵢᵢ
Gauss-Seidel: usa xⱼ⁽ᵏ⁺¹⁾ já calculados para j < i

Critério das linhas (suficiente): |aᵢᵢ| > Σj≠i |aᵢⱼ| → converge.
Gauss-Jordan: identidade no lugar de A; b vira a solução.
Resíduo: r = b − A·x̄.
