Sistemas lineares

O Simplex resolve um sistema em cada pivô. Entender os métodos numéricos de resolução de Ax = b — diretos e iterativos — fecha o ciclo da disciplina. Veja os passos de cada método executando num tableau real.

1 · O problema e a classificação

Resolver Ax = b: encontrar o vetor x que satisfaça simultaneamente as n equações.

A·x = b  ·  A ∈ ℝⁿˣⁿ (coeficientes) · x ∈ ℝⁿ (incógnitas) · b ∈ ℝⁿ (termos independentes)
Compatível

Possível / consistente

Tem ao menos uma solução.
Determinado: solução única (det A ≠ 0).
Indeterminado: infinitas.

Incompatível

Impossível

Nenhuma solução. Ocorre, por exemplo, quando uma linha é múltipla de outra mas o termo independente não acompanha.

Homogêneo

b = 0

Sempre compatível: admite a solução trivial x = 0. Será determinado se det A ≠ 0.

Resíduo Para medir o erro de uma solução aproximada, usa-se r = b − A·x̄. Resíduo pequeno é indício de boa solução, mas não é prova — em sistemas mal condicionados um resíduo minúsculo pode esconder um erro enorme na solução.

2 · Substituição retroativa

Se A é triangular superior, resolve-se de baixo para cima: da última equação vem xₙ; substituindo na penúltima vem xₙ₋₁, e assim por diante.

xₙ = bₙ / aₙₙ   ;   xᵢ = ( bᵢ − Σj>i aᵢⱼ·xⱼ ) / aᵢᵢ

3 · Métodos diretos

Chegam à solução (a menos de arredondamento) num número finito de operações.

Eliminação de Gauss

Transforma A numa triangular superior por operações elementares, depois substitui retroativamente.

  1. Pivô. No passo k, o pivô é aₖₖ⁽ᵏ⁾. Se for zero, troca-se a linha com outra abaixo cujo coeficiente na coluna k não seja zero (nunca com linha acima — isso desfaria as eliminações já feitas).
  2. Multiplicadores. Para cada linha i > k: mᵢₖ = aᵢₖ / aₖₖ. A linha i vira Lᵢ ← Lᵢ − mᵢₖ·Lₖ.
  3. Repetir até a forma triangular.
  4. Substituir retroativamente.
Pivotação Para minimizar a propagação de erro, escolhe-se como pivô o elemento de maior valor absoluto na coluna (pivotação parcial) ou em toda a submatriz (pivotação completa). Assim todos os multiplicadores ficam com módulo ≤ 1, evitando amplificar erros.

Gauss-Jordan

Vai além de Gauss: em cada passo elimina também acima do pivô, deixando a matriz na forma da identidade. O vetor b se transforma diretamente na solução.

4 · Métodos iterativos

Em vez de triangular, reescreve-se o sistema como x = Bx + g e itera-se x⁽ᵏ⁺¹⁾ = B·x⁽ᵏ⁾ + g a partir de um chute inicial. Vantajoso em sistemas grandes e esparsos, e autocorretivo (erros não se acumulam).

Processo iterativo:   x⁽ᵏ⁺¹⁾ = B·x⁽ᵏ⁾ + g  ·  converge se ρ(B) < 1

onde ρ(B) = max|λᵢ| é o raio espectral. Como calcular autovalores é caro, usa-se uma condição suficiente:

Critério das linhas (condição suficiente)

A sequência converge se a matriz for estritamente diagonal dominante:

|aᵢᵢ| > Σj≠i |aᵢⱼ|    para todo i

Jacobi

Usa os valores antigos de todas as variáveis para calcular as novas:

xᵢ⁽ᵏ⁺¹⁾ = ( bᵢ − Σj≠i aᵢⱼ·xⱼ⁽ᵏ⁾ ) / aᵢᵢ

Gauss-Seidel

Usa os valores já atualizados assim que ficam disponíveis — em geral converge mais rápido:

xᵢ⁽ᵏ⁺¹⁾ = ( bᵢ − Σj<i aᵢⱼ·xⱼ⁽ᵏ⁺¹⁾ − Σj>i aᵢⱼ·xⱼ⁽ᵏ⁾ ) / aᵢᵢ

5 · Mal condicionamento

Um sistema é mal condicionado quando pequenas perturbações nos coeficientes ou em b causam grandes mudanças na solução. Geometricamente, as retas são quase paralelas — o ponto de interseção é extremamente sensível.

Quase paralelas = interseção instável perturbe b e veja a solução saltar
Perturbação em b₂0.00
Solução —

O sistema é x₁ + x₂ = 2 · x₁ + 1.01x₂ = 2.01. Uma variação de 0,05 no lado direito desloca a solução enormemente — típico de A quase singular.

Direto × Iterativo — o que dizer na prova Diretos (Gauss, Jordan): número finito de operações, sem erro de truncamento, mas sofrem com arredondamento em sistemas grandes. Iterativos (Jacobi, Gauss-Seidel): erro de truncamento controlado pela tolerância, autocorretivos, exigem convergência garantida. Não há um sempre melhor — depende da esparsidade e do porte do sistema.
